# Edge 自动读取连接

首次安装：在 Edge 打开 `edge://extensions`，启用“开发人员模式”，选择“加载解压缩的扩展”，选择本文件夹。组件会打开本机工作台并自动配对。以后保持 Edge 打开、登录小红书，在工作台启动研究即可。

每次读取会打开专用小红书标签页，按公司从面经、薪资、工作体验、成长等 11 组检索中去重读取，目标为至少 20 篇原帖及可见评论。若结果不足、访问受限或十分钟内未完成，报告会写明实际篇数和原因，不会把未读帖子计入。它不是全站爬虫；明显内推/付费标题初步排除，正文由研究任务进一步判断并交叉核验。更新连接组件文件后，在 `edge://extensions` 点击该扩展的“重新加载”一次。

登录或验证提示出现时，在专用标签页处理，组件会自动重试。超过10分钟仍未完成时，本轮保留已读内容并明确标注不足。电脑休眠、浏览器关闭、页面结构变化都可能导致本轮读取未完成。

权限仅包括本机工作台与小红书页面、脚本读取、连接状态存储和周期检查。未请求 Cookie、密码、浏览历史、下载或剪贴板权限。不会发帖、评论、点赞、私信或申请职位。只有工作台已有读取任务时才访问小红书。浏览器检查周期不调用 AI；岗位分析继续沿用现有 Plus 执行流程。

连接密钥保存在本机 .local/edge-connection.json 和扩展私有存储内；不要分享该文件。结果只保存公开原帖链接，去除链接中的临时访问参数。更新组件后，在扩展管理页点击重新加载，并刷新工作台。

安装方式依据：[Microsoft Edge 本地加载说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。
